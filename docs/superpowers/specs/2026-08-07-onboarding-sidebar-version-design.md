# 首次设置侧栏版本号设计

## 目标

在 Mac Face Lock 首次安全设置界面的左侧栏底部显示当前应用版本，帮助用户在截图、反馈和现场排查时快速确认正在使用的版本。

## 范围

- 仅调整首次安全设置界面的左侧栏。
- 在现有“所有人脸资料和运行记录只保存在本机。”说明下方显示版本。
- 显示格式为 `v0.2.0`。
- 不调整主界面、设置页、状态菜单、版本号本身或发布流程。

## 版本来源

界面从当前应用包的 `CFBundleShortVersionString` 读取版本，不在 Swift 界面代码中写死具体版本。读取结果去除首尾空白；键缺失或结果为空时不显示版本文字，避免展示错误或占位版本。

## 视觉呈现

版本号与本地保存说明左对齐，放在同一个底部信息区域内。版本号使用比说明文字更弱的层级：小号字体、次要文字颜色，并与说明保持紧凑但清晰的垂直间距。侧栏原有宽度、步骤列表和主内容布局不变。

## 实现边界

版本读取逻辑保持为一个小而独立的值转换入口，使界面只负责决定是否渲染 `v<版本>`。不把 `SetupCoordinator`、首次设置记录或运行时状态引入版本显示数据流。

## 验证

- 自动测试先证明当前界面缺少动态版本显示，再驱动实现。
- 测试验证版本来自 `CFBundleShortVersionString`，并拒绝在界面中写死 `v0.2.0`。
- 现有打包测试继续验证发行版 `CFBundleShortVersionString` 为 `0.2.0`。
- 构建并安装后，目视确认左下角显示 `v0.2.0`，同时检查窄窗口、浅色和深色外观下没有截断或层级冲突。
