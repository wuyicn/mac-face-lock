# 普通客户安装与首次设置

本指南面向直接下载桌面发行包的普通客户。您无需安装 Codex、Python、Xcode、终端工具或源码仓库。

## 下载、校验与安装

1. 在项目的 GitHub Releases 页面下载 `Mac-Face-Lock-0.2.0-beta-arm64.zip` 和同名 `.sha256` 文件。
2. 在 Finder 中解压 ZIP。SHA-256 校验值应与 `.sha256` 文件一致；若下载来源、文件名或校验结果可疑，请不要运行。
3. 把 `Mac Face Lock.app` 拖入“应用程序”。
4. 当前 Beta 使用临时签名且未经过 Apple 公证。首次启动时，在 Finder 中对应用右键，选择“打开”，再确认“打开”。不要用关闭 Gatekeeper 的方式绕过检查。

## 首次设置

应用会依次显示以下页面：

1. **准备检查**：检查系统版本、应用位置、内置运行组件和本地存储。
2. **权限中心**：按按钮进入系统设置，允许控制中心使用摄像头；屏幕录制仅在启用锁屏前截图时需要。
3. **录入本人**：按提示完成正脸、左转、右转、轻微低头和轻微抬头。画面太暗、人脸太远、多人入镜或动作不符时，应用会要求重试，不会保存不完整模板。
4. **安全测试**：确认后台 Agent 的摄像头、输入监控和辅助功能权限，并执行不会锁屏的本人验证。
5. **完成并开启**：只有所有必需检查通过后才会启用保护。

所有识别默认在本机完成。当前版本没有活体检测，不能替代登录密码、Touch ID、FileVault 或其他系统安全能力。

## 权限没有生效时

- 回到应用的“权限中心”点击刷新。
- 若系统设置显示已开启但应用仍提示缺失，先关闭对应权限，再重新开启。
- 移动或更新应用后，macOS 可能把它视为新的程序；请重新授权，并再次运行“安全测试”。
- 后台 Agent 与控制中心是两个独立组件。安全测试页显示的是 Agent 的摄像头、输入监控和辅助功能权限。
- 仍无法修复时，保留应用显示的错误信息；不要发送人脸模板、照片、证据或完整日志到公开 Issue。

## 重新录入本人

在设置中选择“重新录入本人”后，完整完成五个动作。录入取消、超时或失败时，原有可用模板会保留；新模板仅在全部动作通过后替换旧模板。

## 升级旧版

若检测到已知的源码测试版，发行版会要求确认一次不可恢复的旧版清理。旧人脸模板和设置不会导入；清理后需重新授权、录入本人并运行安全测试。若应用提示旧版结构不完整，请使用界面中的“复制诊断摘要”“保存诊断摘要”和“打开处理指南”，不要自行猜测并删除文件。

## 卸载与删除数据

### 保留数据

退出 Mac Face Lock，把“应用程序”中的 `Mac Face Lock.app` 移到废纸篓。普通卸载会停止发行版服务，但保留数据，方便以后重装继续使用。

### 彻底删除

彻底删除会永久移除本人模板、设置、活动记录、日志和可选证据。请先确认不再需要这些数据：

1. 先按上面的“保留数据”步骤卸载应用。
2. 在 Finder 中选择“前往 → 前往文件夹…”。
3. 输入 `~/Library/Application Support/Mac Face Lock`。
4. 再次确认文件夹属于 Mac Face Lock，然后将其移到废纸篓并清空。

如果路径不存在，说明没有保留的发行版数据。不要删除其他 Application Support 文件夹。
