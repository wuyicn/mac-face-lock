# 旧版安装无法自动确认时怎么办

当前发行版只有在结构完全匹配已知版本时才会执行操作。未知或混合的新旧结构不会被猜测处理：保护会继续保持关闭，应用不会删除任何文件。

## 出现“保留数据”按钮时

如果页面显示“移除已知旧版后台注册并保留数据”，表示当前发行版精确识别出一个落单的旧版后台注册：

1. 点击“移除已知旧版后台注册并保留数据”。
2. 阅读确认框；确认后，应用只移除这个后台注册并确认服务已经停止。
3. 旧版本的本人模板、设置、活动记录、日志、源码和应用文件等源数据全部保留。
4. 操作成功后，按页面提示继续首次设置。

整个过程都在当前发行版界面中完成，不需要寻找或重新打开旧版本。

## 没有出现该按钮时

这表示结构不是应用能够安全识别的单个残留。未知或混合结构会继续保持阻塞，并且不会提供自动删除按钮：

1. 点击“保存诊断摘要”。摘要只包含阻塞状态、原因代码和旧服务文件是否存在，不包含人脸模板、配置内容、日志内容或原始路径。
2. 点击“重新检查”，确认问题不是一次临时读取失败。
3. 若仍阻塞，请保留诊断摘要和当前页面提示，不要移动或删除未知项目。

在问题解决前，请继续使用 macOS 密码、Touch ID 和系统锁屏。不要公开上传人脸文件、照片、证据、配置或完整日志。
