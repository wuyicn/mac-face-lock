# 旧版安装无法自动确认时怎么办

Mac Face Lock 只有在能够严格确认“旧 Agent”和“旧状态服务”都属于同一套已知源码测试版时，才会自动清理。结构不完整、混合了新旧版本或包含未知文件时，应用会保持保护关闭，不停止服务，也不删除任何文件。

请按以下顺序处理：

1. 在 Mac Face Lock 的提示卡片中选择“保存诊断摘要”。摘要只包含阻塞状态、原因代码，以及旧服务文件是否存在；不包含人脸模板、配置内容、日志内容或原始路径。
2. 如果你仍保留以前的源码测试版，请打开那一版 Mac Face Lock 自带的卸载入口并选择“卸载后台服务”。不要自行查找或删除开发目录。
3. 退出所有 Mac Face Lock 窗口，重新打开当前发行版，然后选择“重新检查”。
4. 如果仍然阻塞，请把诊断摘要附到项目的私密安全报告或维护者指定的支持渠道。不要公开上传人脸文件、配置、日志、照片或整个应用支持目录。

在问题解决前，请继续使用 macOS 密码、Touch ID 和系统锁屏。不要尝试运行终端命令、修改启动服务文件或移动未知旧目录。
